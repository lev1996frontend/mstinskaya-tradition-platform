# Handoff: Река с корабликом — раскрытие блока «Буза»

## Overview
Игровая механика для раздела «Буза» (истоки традиции) на главной странице: тонкая полоса-река встроена прямо под хедером, по ней плывёт кораблик. Клик по кораблику раскрывает («причаливает» к берегу) полный контент секции «Буза», которая до этого показана свёрнутой — только заголовок и короткая подсказка.

## About the Design Files
Файл `Текущая главная (из кода).dc.html` в этом бандле — HTML-референс поведения и вида, а не код для прямого копирования. Механику нужно воссоздать в реальном стеке проекта (Next.js/React, судя по `frontend/src/app/page.tsx`), используя существующие паттерны компонентов (`components/layout/site-header.tsx`, `features/home/*`).

## Fidelity
Hifi для геометрии/цветов реки и кораблика и для тайминга анимаций; можно адаптировать под реальные брейкпоинты и системы токенов проекта.

## Где это живёт
- Река: узкая полоса **внутри `<header>`**, сразу под строкой навигации, во всю ширину контейнера хедера (не ограничена `max-width`).
- Раздел «Буза»: между блоком объявлений турниров (bulletin) и секцией «Стенка/Круг», `id="buza"`.

## Механика пошагово

1. **Река в хедере** — `<div>` высотой 44px, фон — вертикальный градиент тёмный-в-тёмный (`#100e0c` → `#161310`), с верхней границей `1px solid #241c15`.
   - Внутри — SVG на всю ширину/высоту (`viewBox="0 0 1440 44"`, `preserveAspectRatio="none"`):
     - Заливка «дна реки»: волнообразный path (кубические Безье, амплитуда ~18px) с `fill: #1c2b30`, `opacity: 0.55`, замкнутый снизу до низа вьюбокса.
     - Линия течения: тот же волновой path, но `fill: none`, `stroke: #4a6d75`, `stroke-width: 1.6`, `stroke-dasharray: 7 7`, `opacity: 0.75` — с бесконечной CSS-анимацией `stroke-dashoffset` (0 → -48 за 3.2s, `linear infinite`), создающей эффект течения.
   - Кораблик — `<button>` 30×24px, `position: absolute`, без фона/рамки, курсор `pointer`. Иконка — боковой силуэт кораблика (корпус + мачта + два треугольных паруса), SVG `viewBox="0 0 29 24"`, цвет `#d9a44e` (золото/охра, акцентный тон проекта).
   - Анимация плавания кораблика — CSS `@keyframes`, 26s `linear infinite`, по `left`/`top`/`transform: rotate()`, повторяющая изгиб волны реки (примерно 5 контрольных точек: `left: 3% → 26% → 50% → 74% → 3%`, `top` варьируется 12–24px в противофазе с рекой, лёгкий наклон `rotate(±3deg)` для «покачивания»). На середине цикла (`50%` → `50.01%`) кораблик зеркалится по горизонтали (`scaleX(-1)`), чтобы визуально развернуться и «плыть обратно», не выглядя рывком/телепортом.
   - `:hover` ставит анимацию на пауза (`animation-play-state: paused`) — сигнал интерактивности без явной подсказки/подписи.

2. **Клик по кораблику** — вызывает единый toggle-хендлер (тот же, что дублирован как fallback на логотипе шапки, если нужен запасной путь входа):
   - Если секция «Буза» закрыта → открыть (проиграть переход, описанный ниже) и установить состояние `open`.
   - Если уже открыта → закрыть обратно (свернуть контент, состояние `closed`).
   - Анимация «сшибки»/удара при открытии: кольцо-вспышка (`border`, растущее от `scale(0.3)` до `scale(2.6)` с падением `opacity`, длительность ~650ms, `cubic-bezier(.2,.8,.3,1)`) — опционально, для тактильности клика.

3. **Раздел «Буза» — свёрнутое состояние (по умолчанию)**
   - Виден: лейбл «Исток традиции» + горизонтальная линия-разделитель, заголовок `<h2>Буза</h2>` (Alegreya, 700, 3rem), и одна строка подсказки цвет `#8b7f6b`: *«Кораблик на реке выше приведёт сюда историю.»*
   - Больше ничего не рендерится/не отображается — весь остальной контент лежит под условием `open`.

4. **Раздел «Буза» — открытое состояние**
   Раскрывается контейнер (плавное появление, класс аналог `pop-in`: `opacity 0→1` + `translateY(6px)→0` + `scale(.94)→1`, ~260ms ease-out) со следующим содержимым:
   - **Левая колонка**: абзац текста о происхождении Бузы (артели, бурлаки, «бузники»); блок «Слово с тремя историями» — три chip-кнопки (Напиток / Буянить / Корабль), клик подсвечивает выбранный chip и показывает под ним объяснение (текст меняется по индексу выбора, дефолт — общая фраза без выбора); pull-quote с частушкой «под Бузу» (курсив, левая рамка-акцент 2px `#b07a35`).
   - **Правая колонка**: заголовок «Как это было устроено» + вертикальный список из 5 шагов обряда (Сбор / Круг / Пляска / Толчки / Уговор) как кликабельные строки-аккордеон — клик разворачивает описание только у выбранного шага (остальные сворачиваются), активная строка чуть светлее фона и с акцентным цветом номера/заголовка.
   - Ниже, во всю ширину — 3-колоночная лента «lineage» (год/веха + короткий текст): 1990 (клуб «Белый волк»), 2011 (вступление в WoMAU), 16 лет (турниры «Мстинская традиция»).
   - Замыкающий абзац, явно связывающий обряд с турнирами сайта («Турниры этого сайта носят то же имя...»).

## Design Tokens (использованные в референсе)
- Фон секции/реки: `#100e0c`, `#161310`, `#1b1611`
- Река — вода: `#1c2b30` (заливка), `#4a6d75` (линия)
- Акцент кораблика/золото: `#d9a44e`, `#b07a35`
- Текст: `#e8dcc4` (основной светлый), `#c9bfa8` (приглушённый), `#8b7f6b`/`#9a8f7c` (вторичный)
- Акцент-красный (для «сшибки»/hover состояний): `#b02a20`
- Шрифты: заголовки — Alegreya (700/600), тело — Commissioner, лейблы/моно-детали — IBM Plex Mono (uppercase, letter-spacing 0.14em)

## Interactions & Behavior
- Клик по кораблику — единственный способ открыть/закрыть раздел (без автоскролла обязательного, но можно добавить smooth-scroll к секции при открытии, если раздел уходит за пределы вьюпорта).
- Наведение на кораблик — пауза анимации плавания (лёгкая обратная связь).
- Chip-кнопки этимологии и шаги обряда внутри открытого раздела — независимое locale-состояние, не связано с открытием/закрытием самого раздела.
- Повторный клик по кораблику — полное сворачивание (не аккордеон «нельзя закрыть»).

## State Management
Минимально:
```
buzaOpen: boolean            // открыт/закрыт весь блок «Буза»
etymologySelected: number|null  // какой из 3 chip выбран (Напиток/Буянить/Корабль)
ritualStepActive: number     // какой из 5 шагов обряда развёрнут (по умолчанию 0)
```
Кораблик и его анимация — чистый CSS/UI-стейт, не требуют серверных данных.

Нет внешних изображений — всё нарисовано как SVG/CSS (волна реки, силуэт кораблика). При желании силуэт кораблика можно заменить на иконку из существующей библиотеки иконок проекта, сохранив пропорции (боковой вид, корпус+мачта+парус).
